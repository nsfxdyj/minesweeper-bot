# verifier v2 — 长目标踩雷 bug（等待后旧坐标点击）修复验收标准

客户反馈：目标 200s 稳定成功，400s+ 经常踩雷。
根因：每轮开始定位一次棋盘 → 配速等待（长目标下单次可达 1-2 分钟）→
等待结束仍用旧坐标点击；广告定时刷新会挤移棋盘 → 点击落到错误格子。

| # | 指标 | 判定标准 |
|---|------|---------|
| B1 | 等待后重读重规划 | before_batch 等待结束后 scan_stable 复检；棋盘不一致则弃用旧计划重新规划，_apply 绝不执行旧坐标（模拟移位单测：点击落在新棋盘的计划点上） |
| B2 | 批中移位修正 | _apply(verify_geo=True) 每 4 步重定位，后续点击使用新 geo（单测：第 5 次点击坐标跟随新原点） |
| B3 | 防屏幕休眠 | Windows 后端 human_move_to 每 >25s 注入一次零位移 mouse_event（MOUSEEVENTF_MOVE keep-alive，源码断言 + 逻辑单测） |
