# verifier v1 — 动态配速 + 拟人游走 验收标准

针对需求：
1. 延迟期间鼠标在"下一个选点之间"不规律小幅度晃动（模拟思考），允许无效操作（悬停/犹豫/绕小圈，禁止点击）。
2. 最终完成时间收束在目标 ±10% 以内；快超时自动加速（减少延迟），过快自动放慢。

## 验收项

| # | 指标 | 判定标准 |
|---|------|---------|
| A1 | 仿真收束 | 模拟对局（快/慢/不均匀三种节奏各 30 局）最终完成时间全部落 [0.9T, 1.1T] |
| A2 | 动态调整 | 控制器在落后计划时降低延迟倍率、超前时提高（仿真日志可证） |
| A3 | 游走幅度 | 游走目标点距"下一候选点集合"最近距离 ≤ 75px（3 格以内），连续两次游走动点间不出现 >150px 的大跳（除非切换到下一候选点） |
| A4 | 不规律性 | 游走间隔时间变异系数 CV ≥ 0.25；步长分布非单点（≥10 种不同步长/100 步） |
| A5 | 无危险操作 | 游走/无效操作期间零点击（backend 记录 click 次数为 0） |
| A6 | 沙箱 e2e | 真实网页 18s/35s 目标：获胜且用时落 [0.9T, 1.1T] |
| A7 | exe 冒烟 | Wine 下 exe 控制台 /state 与页面正常响应 |
