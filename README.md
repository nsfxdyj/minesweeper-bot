# Minesweeper Bot —— 网页扫雷 AI

在 [minesweeper.cn](https://www.minesweeper.cn/) 上自动玩扫雷的 Python 程序。
纯图像识别方案：**不读取网页内部数据**，只看屏幕截图，通过鼠标事件点击，
和人类玩家的信息获取方式完全一致。

## 实测胜率（沙箱内真实点击网页测得）

| 难度 | 棋盘 | 胜率（含精确概率模块） |
|------|------|------|
| 基础 | 9×9 / 10 雷 | **100%**（30/30，0 次猜测） |
| 中级 | 16×16 / 40 雷 | **95%**（19/20） |
| 专家 | 16×30 / 99 雷 | **85%**（17/20） |

## 原理（三层架构）

```
截图 ──► vision.py ──► solver.py ──► 鼠标点击
感知        识别            决策         执行
```

- **感知 `msbot/vision.py`**
  - 定位：画布边框是 2px 灰线（rgb(128)）+ 底部白线，按"长度匹配 + 网格线
    梯度打分"在全屏截图中找到棋盘（自动适配 9×9 / 16×16 / 16×30，
    不受广告把棋盘挤移位的影响——每轮重新定位）；**Windows 显示缩放 /
    浏览器缩放导致格子大于 25px 时自动识别真实格距**，先把棋盘重采样回
    25px 再逐格识别（边框长度同时整除 24×25px 和 16×37.5px 的歧义由
    内部网格线证据裁决）。
  - 识别：未开格看"凸起白边"（顶部亮条 >200），数字按色相规则分类
    （1 亮蓝 / 2 绿 / 3 红 / 4 藏青 / 5 褐 / 6 青 / 7 黑 / 8 灰），
    旗帜、爆雷（红底，看内角像素）、已揭示雷（黑色块 >170px）各有规则。
- **决策 `msbot/solver.py`**
  - 约束传播：数字格 → (未知邻格集合, 剩余雷数) 约束；
    两条确定规则（剩余=0 全安全 / 剩余=格数 全是雷）+
    子集差推理（A⊂B ⇒ B−A 是新约束），迭代到不动点。
    经过性质测试：300 张随机棋盘推断 2955 格零误判。
  - 无确定解时启用**精确概率引擎**（`msbot/probability.py`）：
    把前沿约束拆成独立组件，回溯枚举每个组件的全部合法布雷组合，
    再用全局雷数做卷积加权，算出每个未开格的精确踩雷概率；
    概率 0=必安全、1=必雷（严格强于子集推理），否则取概率最低者猜。
- **执行 `msbot/player.py`**
  - 开棋点中心（首点必不踩雷）；每轮"稳定读取"（连续两帧一致才采信，
    避开级联展开的渲染中间态）；6 轮无进展自动判卡死。
  - 胜利判定：该站规则是**全部雷被正确标记即胜利**（不需要点开所有安全格）。
- **配速 `msbot/pace.py`**（定时模式，动态延迟策略）
  - 闭环控制器：每批操作前比较 `目标 × 批后进度` 与 `已用时`，
    **超前就放慢**（延迟倍率升向 3×）、**落后就加速**（倍率按轮
    几何衰减至 0.12×，预测超时再加狠踩）；最终完成收束在
    **目标 ±10%**（仿真三种节奏 + 真实网页 10s/18s/35s 实测达标）。
  - 每批操作"按调度完成"而非"到点才开工"：等待时长已扣除实测
    批成本（EMA 在线学习每步耗时）；收官批次单独 hold 到
    `目标 − 批成本`，胜利一击精确压线。
  - 等待期间鼠标在**下一批候选点之间**做不规律小幅度"思考"动作：
    候选格旁悬停（σ8px 抖动）、走到中途又折回的犹豫、绕 5-13px
    小圈打量、原地微抖、以及纯盯着看的无效操作——零点击、
    无大幅度规律晃动。
  - **长等待坐标保鲜**（400s+ 场景修复）：每段等待结束后重新读取
    棋盘，页面若在等待中移位（广告刷新挤动棋盘）则弃用旧计划
    重新规划，绝不点击旧坐标；批次执行中每 4 步再重定位一次；
    游走每 25s 注入一次零位移输入防屏幕休眠。
  - **一致性防护**（专家 600s 场景加固）：稳定≠正确——整板误读
    （亚像素重渲染/弹窗遮挡）能骗过稳定读取，所以每次行动前再做
    两道逻辑校验：数字约束必须可满足（邻域 flags ≤ n ≤ flags+未知），
    已翻开数字跨轮不得改变（整板平移则自动重对齐）。校验不过就
    安全暂停，宁可不点也不点错。轮开销（扫描/规划）计入调度 EMA，
    长局不再系统性偏慢。
    实测：基础 240s→240.6s、420s→415.9s；专家 600s 八路并行 8/8
    获胜，用时 607-638s。

## Windows 上运行

**方式一：免安装 exe（推荐，定时配速模式）**

双击 `扫雷机器人.exe`（PyInstaller 单文件打包，无需 Python 环境）：

1. 自动弹出**控制台网页**（127.0.0.1 本地页面，Edge 等默认浏览器直接打开）；
2. 先把扫雷网页（https://www.minesweeper.cn/）打开并保持在**可见**状态
   （可以两个窗口并排，控制台输入完切回游戏页）；
3. 在控制台输入**目标时间（秒）**点"开始"——bot 会把整局节奏控制在
   这个时间左右完成，延迟均匀摊进每次操作间隙，鼠标全程拟人游走；
4. **踩雷失败**：立刻自动重开一局，计时清零，仍按同一目标时间完成；
5. **成功**：bot 停住不动，控制台显示实际用时和战绩；
   输入下一个时间再点"开始"即可下一局。

想全速连玩（旧行为）用命令行：`扫雷机器人.exe --cli 20`。

**方式二：源码运行**

```powershell
pip install -r requirements.txt
# 浏览器打开 https://www.minesweeper.cn/ ，缩放保持 100%（Ctrl+0）
python main.py              # 定时配速模式：自动打开控制台网页
python main.py --cli 20     # 旧模式：全速连玩 20 局，5 秒内切到游戏标签页
```

- **停止方式（系统级，任意窗口聚焦都有效）**：按 `F8`，或把鼠标甩到屏幕角落停 0.4 秒。
  双击运行 exe 时焦点在浏览器上、Ctrl+C 无效的问题由此解决。
- **拟人鼠标（直播友好）**：贝塞尔曲线轨迹 + 先快后慢变速 + 随机步速、
  12% 概率轻微过冲再纠正、每次落点在格内随机偏移 ±7px、动作间隔随机
  （偶尔 0.4-1.1s"思考"停顿）、按下-抬起保持时间 30-90ms。
  鼠标控制直接用 Win32 API（`SetCursorPos`/`mouse_event`），不依赖 pyautogui。
- 想玩中级/专家，先在网页上点对应难度按钮，bot 会自动识别棋盘大小。
- 支持"满屏"和自定义尺寸，但雷数未知时全局猜测退化为按局部概率。

## 文件结构

```
main.py                    Windows 入口（默认控制台模式，--cli 全速连玩）
sandbox_e2e.py             沙箱端到端测试（Playwright 驱动真实网页）
sandbox_paced_test.py      定时配速端到端测试（目标时间达标验证）
msbot/
  vision.py                感知：棋盘定位 + 格子识别
  solver.py                决策：约束传播求解器
  probability.py           决策：精确概率引擎（约束枚举 + 全局卷积）
  humanize.py              拟人：贝塞尔鼠标轨迹 / 随机节奏 / 停止信号
  pace.py                  配速：闭环时间控制 + 空闲鼠标游走
  control_ui.py            控制台：本地网页（输入目标时间 / 显示状态战绩）
  player.py                执行：与后端无关的游戏主循环（play_paced 定时模式）
  backend_windows.py       Windows 后端（mss 截屏 + Win32 API 鼠标 + F8 热键）
  backend_playwright.py    测试后端（Playwright 鼠标事件）
tests/
  test_solver.py           求解器性质测试
  test_probability.py      概率引擎一致性/正确性测试
  test_vision.py           视觉回归测试（含 fixtures 真实截图）
  test_humanize.py         拟人轨迹/落点/节奏测试
verifier/
  v1/criteria.md           配速/游走验收标准（±10% 收束等 7 项）
  v1/check_pacing.py       仿真自动检查（A1-A5）
  runs/                    历次验证运行记录
```

## 已知限制

- Windows 显示缩放（125%/150%/200%）和浏览器缩放已自动适配：视觉层会识别
  真实格距并重采样回 25px 识别（建议仍保持浏览器 100% 缩放，画面最清晰）。
- 网页偶尔渲染出轻微重采样的帧，识别规则已按容差设计覆盖这种情况。
- 枚举组件解数超过 20 万时精确概率退化为启发式猜测（专家级残局偶发）。
- 配速只能"放慢"不能"加速"：目标时间低于 bot 全速完成一局所需的
  时间时，会按最快速度打完（实测基础级约 4-6s、中级约 10-15s）。
  建议目标 ≥ 全速用时的 1.5 倍，画面最自然。
